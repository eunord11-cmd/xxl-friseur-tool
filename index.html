Google Sheets Einrichtung

Einmalige Einrichtung — danach werden alle Artikel automatisch in Google Sheets gespeichert und sind von überall abrufbar.

1
Google Sheet erstellen
Gehe auf sheets.google.com → Neues leeres Sheet → Nenne es „XXL Friseur Lager"
2
Apps Script öffnen
Im Sheet: Erweiterungen → Apps Script → Das Script-Fenster öffnet sich
3
Script einfügen
Den gesamten Inhalt der Datei google_apps_script.js in das Script-Fenster kopieren → Alten Code löschen → Speichern (💾)
4
Web-App veröffentlichen
1. Oben rechts: Bereitstellen → Neue Bereitstellung
2. Typ: Web-App
3. Ausführen als: Ich (deine E-Mail)
4. Zugriff: Jeder
5. Bereitstellen → Berechtigung erteilen → URL kopieren
5
URL hier eintragen
Die Web-App URL unten einfügen → Verbinden klicken → Fertig!
